# מחשבון הפער, אושר פיננסי

מחשבון שמראה למשפחה את הפער בין מה שיצטבר אצלה בפועל לבין מה שהמטרה שלה דורשת.

## מבנה

| קובץ | מה זה |
|---|---|
| `page.html` | **מקור האמת.** הדף המלא, עצמאי, לפיתוח ולבדיקה מקומית |
| `engine.js` | מנוע החישוב. ריבית דריבית, פסקי דין, סדרות לגרף, קרן חירום |
| `build.js` | מפצל את `page.html` ל-`docs/` להפצה |
| `docs/` | **מה שעולה לאוויר.** נבנה אוטומטית, אין לערוך ידנית |

## למה הקוד יושב בקובץ חיצוני

וורדפרס משחית JavaScript שיש בו `<div>` או `&` בתוך מחרוזת. קובץ חיצוני לא עובר
את העיבוד הזה כלל, ולכן `gap.js` בונה את כל ה-HTML בעצמו ובדף באתר נשארות שלוש
שורות בלי שום תגית שאפשר לשבור.

## בדיקות

```
node test.js        # המנוע
node plan.test.js   # תוכנית הילדים
node codex.test.js  # שבעת הממצאים מביקורת קודקס
node dom.test.js    # הדף החי ב-jsdom
node build.js
node dist.test.js   # קבצי ההפצה
```
